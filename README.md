# EPSON PX-M887F「スキャン to メール」設定ガイド

EPSONのビジネス複合機 **PX-M887F** で、スキャンした書類をパソコンを介さず指定のメールアドレスへ直接送信する「スキャン to メール」の設定手順をまとめた、単一ファイル（`index.html`）のインタラクティブ設定ガイドです。

## 公開ページ（GitHub Pages）

- **ガイドを開く:** `https://YOUR_USERNAME.github.io/YOUR_REPO_NAME/`
  （※GitHub Pagesを有効化したあと、ご自身のURLに書き換えてください）

## 主な特徴

- **迷わない2カラム構成**: 左側の全体マップ（目次＋進捗表示）と右側の手順ドキュメントを連動させ、事前準備からテスト送信まで順番に進められます。
- **設定メモ＆コピペ補助ドロワー**: 画面右上のボタンから必要なときだけ開閉できます。製造番号の両端の `*` 除去・大文字化や、SMTPサーバーアドレスの余計な空白・全角・`/` の自動除去に対応しています。
- **ライト／ダークモード切替**: 読みやすいライトモードをデフォルトとし、ワンクリックでダークモードへ切り替え可能です。
- **プライバシー・セキュリティ重視の設計**:
  - 外部ライブラリ・CDNを一切使用しない完全ゼロ依存（オフライン動作可）
  - 厳格な CSP（Content Security Policy）により外部通信を遮断
  - Cookie・`localStorage`・`sessionStorage` は一切不使用
  - ページを閉じる（`pagehide`）と入力値をメモリから自動消去
  - 印刷・PDF保存時は個人情報を含むメモ領域を自動で非表示

## 使い方

### 1. ブラウザーでそのまま開く（おすすめ）
GitHub Pages の公開URLにアクセスするか、リポジトリから `index.html` をダウンロードしてダブルクリックで開きます。
