EPSON PX-M887F「スキャン to メール」設定マニュアル

紙をセットしてタッチパネルを数回タップするだけで、パソコンを介さず指定のメールアドレスへ PDF を直接送信できるようにする手順ガイドです。事前に何も分からない状態から、確認すべき情報の調べ方と管理画面（Web Config）の設定手順を順番にまとめています。

対象機種：EPSON PX-M887F 設定場所：ブラウザー（Web Config） 所要時間目安：10〜15分

1事前に確認・準備するもの

設定を始める前に、以下の3点を手元に控えておきます。右上の「設定メモを開く」を使うと、調べた値を一時メモしてワンクリックでコピーできます（外部送信やブラウザ保存は一切行いません）。

  1. プリンターのIPアドレス
    プリンター本体のタッチパネルで 設定＞ネットワーク設定＞ネットワークステータス を開き、IPv4 の IPアドレス（例：192.168.x.x）を確認します。
  2. 初期管理者パスワード（製造番号）
    プリンター本体（背面や側面など）に貼られているシールに記載された10桁の製造番号（半角英数字・英字は大文字）を確認します。
    ※両端の *（アスタリスク）は含めません。すでに管理者パスワードを変更している場合は、変更後のパスワードを用意します。
  3. 送信元メールのサーバー情報（SMTP情報）
    普段使っているメールソフトや契約プロバイダーの設定資料から、以下の4点を確認します。
    • SMTPサーバーアドレス（送信メールサーバー名）
    • ポート番号（例：587、465、25 など）
    • 暗号化方式（なし / STARTTLS / SSL/TLS）
    • 認証用ユーザー名（メールアドレス） と メールパスワード
補足：Outlook（クラシック）でSMTP情報を確認する方法

Outlook 上部のメニューから以下の順に開きます。

ファイル＞アカウント設定＞サーバーの設定 をクリックし、画面内の 送信メール ∨ を展開します。

表示された「サーバー名」「ポート」「暗号化方法」「認証の有無」を控え、既存の設定が変わらないよう ［×］で閉じてください。

2Web Config 設定値一覧

Step 2 で管理画面の ネットワーク＞メールサーバー＞基本 に入力する項目の一覧です。ご自身のメール環境に合わせて、すべて半角で入力します。

Web Config の設定項目 入力・選択する内容
認証方式 メールサーバーの指定方式（例：SMTP-AUTH）
認証用ユーザー名 送信に使うメールアドレス
認証用パスワード 上記メールアドレスのメールパスワード
送信元アドレス プリンターからの送信元となるメールアドレス
SMTPサーバーアドレス 確認した送信メールサーバー名（例：smtp.example.com）
SMTPサーバーポート番号 確認したポート番号（例：587 や 465）
セキュア接続 確認した暗号化方式（なし / STARTTLS / SSL/TLS）
証明書の検証 セキュア接続が「なし」の場合は 無効

3設定手順（Step 1〜5）

上から順番に進めます。各ステップが完了したら右上の「完了にする」ボタンを押すと、左側の進捗バーに反映されます。

Step 1

Web Config に管理者ログオンする

  1. パソコンのブラウザーを開き、アドレスバーに控えておいたプリンターのIPアドレス（例：192.168.x.x）を入力してアクセスします。
  2. 画面右上の 管理者ログオン をクリックします。
  3. ユーザー名欄は空欄のまま、パスワード欄に10桁の製造番号（半角大文字）を入力して 確認 をクリックします。
確認ポイント画面上部のメニューに スキャン/コピー や ネットワーク などの管理タブが表示されればログオン完了です。
Step 2

メールサーバー情報を登録する

  1. 画面上部のタブと左メニューから ネットワーク＞メールサーバー＞基本 を開きます。
  2. 「2. Web Config 設定値一覧」の項目をすべて半角で入力・選択し、画面下の 設定 をクリックします。
確認ポイント「設定が完了しました」というメッセージが表示されれば保存完了です。
Step 3

接続確認を実行する

  1. 左メニューから メールサーバー＞接続確認 を開きます。
  2. 画面内の 開始 ボタンをクリックして通信テストを実行します。
確認ポイント「接続確認に成功しました」と表示されれば、メールサーバーとの通信・認証設定は完了です。
Step 4

送り先を連絡先（アドレス帳）に登録する

  1. 画面上部のタブと左メニューから スキャン/コピー＞連絡先 を開きます。
  2. まだ登録されていない空きの番号を選び、登録/編集 をクリックします。
  3. 以下を入力・選択して画面下の 適用（または 設定）で保存します。
    • 種別：メール を選択
    • 名前：プリンター画面に表示したい宛先名
    • メールアドレス：スキャンデータの送り先アドレス
    • 常用指定：チェックを入れると本体の宛先一覧の先頭に表示されて便利です
    • SIP URI：空欄のまま（IPファクス専用項目のため不要）
確認ポイント連絡先一覧に戻り、登録した名前とメールアドレスが表示されていれば登録完了です。
Step 5

プリンター本体からテスト送信する

  1. テスト用の原稿を1枚セットします。
  2. PX-M887F 本体のタッチパネルで スキャン＞メール を開きます。
  3. Step 4 で登録した宛先を選択し、スキャンを実行します。
確認ポイント数十秒〜1分ほどで、指定したメールアドレス宛に PDF などのスキャンデータが添付されたメールが届けばすべての設定が完了です。

4つまずきやすいポイント（Q&A）

エラーが出た場合や迷いやすい項目をまとめました。該当する見出しをクリックして確認してください。

「SMTPサーバーアドレスが正しくありません」とエラーが出る場合

入力欄の前後に見えないスペース（空白）や全角文字、余計な記号（/ や http:// など）が混ざっているとエラーになります。

入力欄を一度 Ctrl + A → Delete で完全に空にしてから、半角英数字とピリオドのみで入れ直してください。右上の「設定メモ」を使うと、余計な文字を自動で取り除いてコピーできます。

Microsoft 365 や Google Workspace のアカウントを使う場合

通常のログインパスワードのままでは、セキュリティ仕様により接続確認で認証エラーになる場合があります。

利用しているサービスの管理画面で「SMTP AUTH（認証済みSMTP）」を有効化するか、2段階認証を有効にしたうえで発行する「アプリパスワード」を認証用パスワード欄に入力してください。

5まとめ＆安全運用のポイント

一度「スキャン to メール」を設定しておくと、紙の書類をデータ化して共有する手間が大きく減ります。今後の再設定や別機器への設定では、次の3点を押さえておくとスムーズです。

  • 管理画面（Web Config）の初期パスワードは、本体シールに記載された10桁の製造番号（半角大文字・両端の * 不要）
  • SMTPサーバーの入力は、見えないスペースや全角文字が入らないよう半角のみで入力する
  • アドレス帳登録では、「常用指定」にチェックを入れておくと本体画面の先頭に表示されて便利
安全運用の推奨ポイント：初期の管理者パスワード（製造番号）は本体シールを見れば確認できるため、職場のセキュリティポリシーや設置環境（来客・外部業者の出入りがある場合など）に応じて、Web Config の管理者パスワードを任意のパスワードへ変更しておくとより安全に運用できます。また、メールパスワードを変更した際は Web Config 側の認証用パスワードもあわせて更新してください。

📝 設定メモ＆コピペ補助

🔒 完全ローカル・一時メモリ設計：外部通信は CSP で遮断されており、Cookie や localStorage 等への保存も一切行いません。ページを閉じるか下の「入力をすべて消去」を押すと全項目が即座に消去されます。
↗ ブラウザで Web Config を開く IPv4アドレスを入力すると管理画面へのリンクが表示されます。
両端の * や小文字を含めても自動で「半角大文字10桁」に整形します。
前後の空白・全角を自動除去します（認証用ユーザー名・送信元・宛先用）。
伏せ字のままコピーできます。入力はメモリ上にのみ保持されます。
空白・全角・http://・/ を自動除去して半角小文字に整形します。
「なし」の場合は Web Config の「証明書の検証」を 無効 にします。
